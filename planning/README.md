# planning/

Everything that is not the agent instructions, laid out as technosophia's
`PLANNING.md` says: `task/`, `backlog/` and `decision/`, one file per item,
each directory's `README.md` its convention.

The standing documents, and when to read each:

- `TESTS.md`: how the test suite and the context experiments are built and
  run. Read it before adding a test helper or an experiment scenario.
- `CREDENTIALS.md`: every credential, where it lives and what losing it
  costs. Read it when one is rotated, lost or added.
