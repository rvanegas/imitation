# Tasks

The roadmap: features, audits, open questions and things to go and find out,
one file per item, a paragraph or so each. This is where work is picked up
from. A design for unbuilt work lives in the task that asks for it.

The name is the slug of the `# ` heading (technosophia's `PLANNING.md`);
`ts task "Some Title"` makes one, and `ts note check` holds the rule. `ls` is
the index. Finishing a task deletes its file, in the commit that does it.
